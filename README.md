# HTTP Protocol Caller

## Installation

```go
go get github.com/nlgolib/http_call
```

## Functionality Highlights

- [x] GET/POST/PUT/DELETE Callers
- [x] Add Headers
- [x] Add Params
- [x] Set Request Body
- [x] Return Raw Response
- [x] Return Parsed Response
- [x] Return HTTP Status Code
- [x] URL Params Handling Function
